# Пакет rover

[English](README.en.md) · [ТЗ 1.0](TECHNICAL_SPECIFICATION.md) · [CHANGELOG](CHANGELOG.md)

Отдельный пример: колёсный ровер с роутером, USB-камерой, Arduino-совместимой
платой, драйверами двигателей и АКБ. Браузер смартфона/планшета подключается
по Wi-Fi роутера без Интернета; органы управления накладываются на видео.

Две базы: два приводных колеса и одно опорное либо четыре приводных колеса.
Поворот разницей скоростей сторон, без рулевых сервоприводов. RTU/TCP через ядро;
видео, UI и микшер принадлежат rover.

Пока только черновик, без IPK/прошивки. Предлагаются одна управляющая сессия,
удержание движения, STOP, отказ старым командам, watchdog платы и остановка
при потере видео. Сроки и безопасное состояние требуют согласования.

План веток: контракт безопасности/платы → микшер и сессии на fake I/O →
изолированный UI/видео и замеры → согласованные записи через ядро →
автономный комплект/настройки → отдельно разрешённый моторный стенд.
Сначала питание и вывешенные колёса; движение по поверхности — отдельный опыт.
Wi-Fi профиль готовит mr3020-modes/администратор отдельной операцией;
установка rover сама по себе не меняет сеть.

Требования и история отдельные для будущего выделения репозитория.
Core 1.30 — архитектурная база, не версия готового публичного API.

Зависимость: [контракт системного I/O ядра](../../core/SYSTEM_IO_CONTRACT.md), core 1.31. Уставки/STOP выделены в будущий командный слой; детали разрешений и watchdog ещё открыты.
