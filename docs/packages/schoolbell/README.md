Старые годы читаются без переписи; новая форма сохраняет диапазоны. Pages использует общий редактор/формат и только штатные мелодии. Новый план/backup требует 5.1.0; переносимый комплект с зависимостями пока в плане. Проверки на хосте, без установки.

Schoolbell 5.0.31: исправлены совместимость с opkg без stat, каталоги архива и очистка собственного кэша LuCI. Установка, восстановительный откат и обновление проверены с сохранением данных и выключенными автозвонками; часы/NTP не менялись.

Schoolbell 5.0.28: полный IPK инженерного приложения и закреплённый автономный комплект; host-тесты lifecycle, без установки на роутер. [Поставка](PACKAGING.md).

Установлена5.0.27 с native clock1.0.0: проверены реальная конкуренция замка и подтверждение через браузер. Контроль включён, время подтверждено, автозвонки выключены; часы/NTP не менялись.

5.0.27: занятость результата команды времени означает ожидание, а не отказ; GET ожидает ограниченно, POST не повторяется. Ошибки хранилища отделены от busy.

5.0.26: нативная зависимость и авторизованный интерфейс подтверждения/отключения контроля времени, активация через worker, тесты на хосте. Без установки. [Подробнее](CLOCK_UI.md).


5.0.25: контроль доверия подключён к коду исполнителя; отключаемый режим явно обозначен, проверки на подменяемых часах. На роутер не установлен. Перед установкой нужны нативная зависимость и UI подтверждения: [границы интеграции](CLOCK_EXECUTOR.md).

Проверка на роутере: свежая копия с одной пользовательской мелодией восстановлена через страницу; повторный экспорт совпал побайтно, автозвонки выключены. Это не испытание отключения питания или всех предельных квот.


5.0.24: состояние резервной копии и скачивание повторяют GET при временной занятости не более четырёх раз с паузами 200/500/1000 мс. Скачивание сохраняет общий таймаут 180 с. Восстановление POST автоматически не повторяется; после исчерпания ожидания доступна проверка состояния.


5.0.23: пробелы названия и имени файла кодируются как %20 для CGI LuCI 19.07; буквальный плюс сохраняется как плюс.


5.0.22: токен защиты потоковой загрузки MP3 и восстановления передаётся в Authorization: Bearer — заголовке, поддерживаемом CGI uhttpd 19.07. Сессия LuCI и точное совпадение CSRF-токена по-прежнему обязательны; токен не попадает в URL. Ранее X-CSRF-Token отбрасывался CGI и приводил к HTTP403 до записи файла.

5.0.21: при неподтверждённой загрузке сохраняются исходная ошибка и номер операции; список перечитывается без повторной отправки файла. Если чтение не удалось, прежние строки остаются видимыми, но недоступны до обновления. Это диагностическое исправление; причина отказа браузерной загрузки пока не установлена.

5.0.20: временный busy списка медиатеки вызывает до четырёх GET с паузами 200/500/1000 мс. Старый список после исчерпания повторов обозначен неподтверждённым, действия блокируются, обновление доступно. busy не называется повреждением. POST загрузки не повторяется.

Schoolbell 5.0.19: исправлен пустой HTTP-аудиоответ LuCI на Lua 5.1. Потоковые source/sink используют coroutine-safe защиту на всём пути; тестируются паузы загрузки/скачивания и очистка после обрыва.

Schoolbell 5.0.18: после подтверждённой загрузки список медиатеки перечитывается автоматически. Каждая непустая строка имеет кнопку прослушивания в браузере; пустые слоты обозначены в таблице и списках выбора, прослушивание для них недоступно. При сбое перечитывания сохранённый файл не отправляется повторно. Демо включает все шесть штатных мелодий. Host-проверки без звука; роутер не обновлён.

Schoolbell 5.0.17: скачивание резервной копии ограничено 180 секундами целиком, включая тело ответа. При таймауте/обрыве управление возвращается; сначала нажмите «Проверить состояние», затем повторите скачивание. Запоздалый ответ не сохраняется, восстановление автоматически не запускается. Демо Pages показывает дату сборки UTC и коммит. Проверено на хосте; роутер не обновлялся.

Schoolbell 5.0.16: календарь открывается в режиме просмотра; нажатие даты показывает звонки черновика, не стирая назначение. Для раскраски явно выберите расписание или ластик. Общая плашка различает черновик и активную копию. Сначала сохраните правки, затем отдельно примените проверенную ревизию: изменение плана другим окном требует повторной загрузки. Предпросмотр не подтверждает выполнение. Проверки выполнены на хосте и в браузерном демо; роутер не обновлён.

Schoolbell 5.0.14: сохраняемая громкость колонок роутера в настройках; действует со следующего звонка, Mute останавливает текущий. Системный микшер не меняется.

Автозвонки: отдельная служба автоматических fixed/annual звонков, явное применение сохранённого плана, Mute и отсутствие догоняющего проигрывания. После reboot/смены TZ требуется проверка часов и повторное включение. Системные часы и NTP не изменяются.

## Предварительная поставка примера

`make build-schoolbell` создаёт `out/modbus-schoolbell_0.0.1_all.ipk`;
версия задаётся отдельно через `SCHOOLBELL_VERSION`. Сборка входит в `make all`.
Это media-only preview: `/usr/share/modbus-schoolbell/melodies/test.mp3` и NOTICE,
без служб, cron, player, конфигурации и автоматического звука. Зависимость от
будущего API появится с функциональным портом; сейчас совместимость не заявлена.

[Исходный набор мелодий](../../../packages/schoolbell/media/README.md):
шесть MP3; в IPK только самый короткий test.mp3 (около 3,28 с, 13104 байта).
CI проверяет manifest и точный состав IPK с Python 3.8+ на машине сборки.
На роутер preview-пакет не установлен. Ручное воспроизведение его MP3 через
madplay подтверждено пользователем; это не проверка функционального пакета.

Для первого опыта: подключить колонки с минимальной громкостью, затем проверить
наличие player, аудиоустройство и USB-питание. После отдельного согласования —
одно воспроизведение короткого файла и очистка временных файлов. Установка player,
изменение mixer/драйверов и звук не выполняются одной лишь сборкой IPK.

ТЗ 1.3 принимает владение аудиоисполнителем, FIFO/сроками/отменой из ядра; добавлены автономные зависимости и постоянное хранение. Ручной звук подтверждён, функциональная поставка ещё не реализована.

ТЗ 1.4 задаёт функциональную полноту относительно оригинала: два режима расписаний, предзвонки, время из браузера, локальный UI и пять мелодий плюс test. Добавлены плановые TC-14–33, медиатека и backup. Preview 0.0.1 и runtime не изменены.

Отдельное задание CI schoolbell запускается по изменениям пакета или его зависимостей; локально: `make ci-schoolbell`. Подробнее: [CI](../../CI.md). Аппаратная приёмка остаётся отдельной.

ТЗ schoolbell 1.5 уточняет владение схемой/миграциями, проверку календаря/медиа и шаблон партии отдельно от backup по core 1.16. TC-34/35 плановые; функциональность и preview не изменены.

ТЗ 1.6: изолированный Lua-календарь с постоянным/годовым режимами, тихими датами, предзвонками через полночь и отказом gap/fold. 29 групп, 14404 независимых проверок дат и исходные 15+6 на полном високосном году. Без ядра/звука/роутера; media-only IPK прежний, полный паритет остаётся впереди.

[Calendar API](CALENDAR.md) · `make test-schoolbell`

ТЗ schoolbell 1.7: изолированная Lua-очередь проигрывания, FIFO по ресурсу, монотонный TTL/UTC, отмена владельцем и подменяемый player. 24 группы host-тестов; неизвестный исход удерживает ресурс. Без ядра/процессов/звука/роутера; media-only IPK прежний.

[Очередь проигрывания](PLAYBACK_QUEUE.md) · `make test-schoolbell`

ТЗ schoolbell 1.8: принят контракт системного проигрывателя — launching/exit, удержание ревизии мелодии и блокировка после сбоев. TC-43–49 плановые; реализация, звук, IPK и роутер не изменены. [Player adapter](PLAYER_ADAPTER.md).

ТЗ schoolbell 1.9: приняты нативные механизмы player и begin/poll/release, flock с наследованием FD, файл через stdin, timeout 2000 мс и /dev/null. TC-50–55 плановые; свойства madplay требуют проверки. Код и роутер не изменены. [System API](PLAYER_SYSTEM_API.md).

ТЗ schoolbell 1.10: точные поля результатов/ошибок, подтверждение exec через идентичность executable, кадр 16 байт и бюджеты 64/64/8/8. TC-56–60 плановые; только требования, без изменения кода и роутера. [Results API](PLAYER_RESULTS.md).

ТЗ schoolbell 1.11: закреплены SBPE/v1 big-endian, поколения, счётчик попыток и диапазоны параметров. TC-61–65 плановые; только требования, без кода/звука/роутера. [Wire contract](PLAYER_WIRE.md).

ТЗ schoolbell 1.12: изолированные Lua-кодек SBPE и модель API проигрывателя с подменяемыми операциями. 32 группы host-тестов: кадры, поколения, сроки/исходы, квоты и очистка. Без native binding, процессов, звука, ядра и изменений роутера; IPK прежний. [Player model](PLAYER_MODEL.md).

ТЗ schoolbell 1.13: изолированный Linux C-адаптер проигрывателя и тестовый ребёнок без аудиоустройства; 13 host-групп процессов/отказов, FD и наследование flock после аварии владельца. Без Lua binding, ядра, madplay/звука и изменений роутера; IPK прежний. [Linux player](LINUX_PLAYER.md).
