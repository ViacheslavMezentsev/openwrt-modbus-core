# Достоверность времени schoolbell

[English](CLOCK_TRUST.en.md)

Принятый контракт ТЗ 1.31, раздел 4.7. **Только требования:** schoolbell 5.0.14 не получает новую реализацию, прошивка/службы/часы/NTP не меняются. TC-113–119 — плановые проверки, не пройденные тесты.

| Статус | Условие | Автоматические звонки |
| --- | --- | --- |
| Не подтверждено | Новая загрузка, нет пригодной опоры/контекста | Заблокированы |
| Обнаружен откат | UTC раньше сохранённой подтверждённой отметки более чем на 5 с | Заблокированы |
| Подтверждено | Принято подтверждение с указанным источником | Можно отдельно включить |
| Требуется проверка | Скачок, ошибка контроля, превышение согласованной неопределённости | Заблокированы |

После reboot сохранённая отметка даёт нижнюю опору, а не длительность отключения и не доверие. Положительное сравнение с ней не доказывает точность. При непрерывной работе сравниваем приращение UTC с приращением монотонных часов. Скачок строго больше 5 с в любую сторону требует проверки; равенство не считается срабатыванием. Пороги настраиваемые; диапазоны, частота наблюдения и точность измерения ещё открыты. Перевод локального часа при DST сам по себе не является скачком UTC.

Первый этап: сохраняемая отметка/источник/checksum, статусы, блокировка на сервере, ручная сверка. Пользователь подтверждает показанные часы отдельно от включения плана. Браузер только помогает сверке. Ошибка сохранения или устаревший контекст не дают успеха. Исправление ошибочно будущей опоры требует явного подтверждения расхождения; watermark уже рассмотренных звонков не понижается. Сетевое автоматическое подтверждение и RTC будут отдельным этапом после выбора критериев качества.

Потеря доверия запрещает новые автоматические звонки/предзвонки и отменяет прежнее разрешение. Уже допущенный звук доигрывает; Mute действует. Ручной звонок остаётся доступен с обычными ограничениями. Подтверждение не возобновляет проигрывание; требуется явное включение, без догоняющих/повторных звонков. Проверка есть и перед допуском запуска, а не только в кнопке UI.

В плашке — статус, причина, источник и дата подтверждения; в журнале — переходы и действия, без записи каждого опроса. Год плана сохраняется независимо от часов. Нет плана для текущего года — тишина. Нельзя устанавливать часы из года плана. Копирование на другое устройство не переносит опору/доверие/разрешение запуска.

Открыто: формат записи и миграция; период сохранения/износ flash; диапазоны порогов; бюджет наблюдения и свежесть подтверждения; NTP/RTC качество; допустимая ошибка и срок автономного доверия. Порог 5 с не является обещанной точностью звонка. Отсутствие отката не выявляет весь неизвестный простой. Суточный пассивный опыт не даёт гарантии годовой точности. Общий API ядра этим контрактом не изменяется.
