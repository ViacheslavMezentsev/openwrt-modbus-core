# История изменений

[English](CHANGELOG.en.md)

## [Unreleased]

- Сохранён принятый автономный макет schoolbell: годовой календарь, расписания, медиатека, состояния проигрывателя и системная/тёмная/светлая темы. Только тестовые данные; без API, звука, изменений роутера и включения в IPK.

- ТЗ schoolbell 1.13: изолированный Linux C-адаптер проигрывателя и тестовый ребёнок без аудиоустройства; 13 host-групп процессов/отказов, FD и наследование flock после аварии владельца. Без Lua binding, ядра, madplay/звука и изменений роутера; IPK прежний.

- ТЗ schoolbell 1.12: изолированные Lua-кодек SBPE и модель API проигрывателя с подменяемыми операциями. 32 группы host-тестов: кадры, поколения, сроки/исходы, квоты и очистка. Без native binding, процессов, звука, ядра и изменений роутера; IPK прежний.

- ТЗ schoolbell 1.11: закреплены SBPE/v1 big-endian, поколения, счётчик попыток и диапазоны параметров. TC-61–65 плановые; только требования, без кода/звука/роутера.

- ТЗ schoolbell 1.10: точные поля результатов/ошибок, подтверждение exec через идентичность executable, кадр 16 байт и бюджеты 64/64/8/8. TC-56–60 плановые; только требования, без изменения кода и роутера.

- ТЗ schoolbell 1.9: приняты нативные механизмы player и begin/poll/release, flock с наследованием FD, файл через stdin, timeout 2000 мс и /dev/null. TC-50–55 плановые; свойства madplay требуют проверки. Код и роутер не изменены.

- ТЗ schoolbell 1.8: принят контракт системного проигрывателя — launching/exit, удержание ревизии мелодии и блокировка после сбоев. TC-43–49 плановые; реализация, звук, IPK и роутер не изменены.

- ТЗ schoolbell 1.7: изолированная Lua-очередь проигрывания, FIFO по ресурсу, монотонный TTL/UTC, отмена владельцем и подменяемый player. 24 группы host-тестов; неизвестный исход удерживает ресурс. Без ядра/процессов/звука/роутера; media-only IPK прежний.

- ТЗ schoolbell 1.6: изолированный Lua-календарь с постоянным/годовым режимами, тихими датами, предзвонками через полночь и отказом gap/fold. 29 групп, 14404 независимых проверок дат и исходные 15+6 на полном високосном году. Без ядра/звука/роутера; media-only IPK прежний, полный паритет остаётся впереди.

- ТЗ schoolbell 1.5 уточняет владение схемой/миграциями, проверку календаря/медиа и шаблон партии отдельно от backup по core 1.16. TC-34/35 плановые; функциональность и preview не изменены.

- ТЗ 1.4 задаёт функциональную полноту относительно оригинала: два режима расписаний, предзвонки, время из браузера, локальный UI и пять мелодий плюс test. Добавлены плановые TC-14–33, медиатека и backup. Preview 0.0.1 и runtime не изменены.

- ТЗ 1.3 принимает владение аудиоисполнителем, FIFO/сроками/отменой из ядра; добавлены автономные зависимости и постоянное хранение. Ручной звук подтверждён, функциональная поставка ещё не реализована.

- Перенесены шесть исходных MP3 с manifest; предварительный IPK 0.0.1 включает только test.mp3 и NOTICE. ТЗ 1.2 ссылается на core 1.7; player/scheduler пока отсутствуют.

- ТЗ 1.1 ссылается на принятую политику ядра 1.6; прикладные требования и runtime не менялись.

- Выделено собственное ТЗ 1.0 и пространство требований/тестов. Runtime не изменён.
