# Строгий JSON-декодер Lua

Штатный modbus.json_strict входит в IPK ядра, работает на Lua 5.1 без LuCI.
Требование core 6.9.8, TC-128.

API json.decode(text, limits): успех — value, nil, root_number_form;
отказ — nil, {code=..., offset=...}. Offset — позиция байта от 1,
включая позицию после конца ввода. Частичный результат не возвращается.
Проверять err, а не истинность value: false является допустимым результатом.

json.null сохраняет null и плотность массивов. json.kind(value) различает
object, array, null и обычные типы Lua, включая пустые контейнеры.
json.number_kind(container, key) возвращает integer для числового токена без
точки/экспоненты, number для остальных чисел. Корневая форма — третий результат.
Метаданные описывают исходный разбор, не последующие изменения таблицы.
Проверять схему до модификаций. Старый encoder не сохраняет эти типы/null.

Отвергаются дубли ключей после escape-декодирования, неверный UTF-8, непарные
суррогаты, управляющие символы, комментарии, BOM, лишние запятые, неверная
грамматика чисел и данные после значения. Числа конечны, модуль не более
9007199254740991. Дроби имеют обычные округление и underflow Lua number.
Диапазоны и целочисленная форма полей проверяются схемой отдельно.

| Параметр | Максимум по умолчанию |
| :--- | ---: |
| bytes | 16384 байта входа |
| depth | 8 уровней контейнеров, корневой = 1 |
| nodes | 4096 значений и ключей суммарно |
| string_bytes | 16384 байта декодированной строки/ключа |

Пределы можно только уменьшать положительными целыми числами. Неизвестные
параметры, неверные типы и metatable параметров отвергаются.
Размер входа проверяется до разбора. Это не общий бюджет RAM.

modbus.json.decode_strict(text, limits) предоставляет явный строгий API.
Прежний decode сохраняет необязательный luci.jsonc; кэш, топики и CLI не
мигрированы. Lua-загрузчик профилей должен использовать depth=3, проверять
схему, ID и доверенный каталог. Его реализация и измерение RAM ещё впереди.

Проверки: lua5.1 scripts/test_json_strict.lua (20 групп), make all.
