# Ядро

[English](README.en.md)

Ядро владеет публичными событиями, подписками, уведомлениями, общим scheduler и Modbus. Прикладные обработчики и аудиоисполнитель принадлежат клиентским пакетам. Общий API и управляемая автономная установка пока не реализованы.

[ТЗ 1.9](TECHNICAL_SPECIFICATION.md) · [CHANGELOG](CHANGELOG.md)

ТЗ остаётся черновиком. Номера требований и тестов локальны этому компоненту;
при ссылке указывать `core`, `demo` или `schoolbell`. Ревизия ТЗ не является
версией API. Историю до разделения сохраняет общий CHANGELOG; дальнейшие
изменения компонента отражаются здесь и в его ТЗ. Исследования остаются локальными.

Исправлена граница ядро/клиент: аудио перенесено в schoolbell с историческими указателями. ТЗ 1.8 задаёт публичные события и автономный допуск расширений, проверки места/загрузки/отката/reboot; реализация и численные резервы остаются открытыми.

ТЗ 1.9 расширяет план общего событийного API, scheduler и системного времени. TC-56–60 плановые; транспорт, квоты и политика коррекции часов открыты. Runtime не изменён.
