# Архив документации

[English](README.en.md) · [Актуальные документы](../README.md)

[Завершённые этапы](completed-stages.md) вынесены из TODO; остающиеся работы
собраны в [TODO](../../TODO.md). Архивирование не означает выполнения всех
идей старых планов или утверждения их численных обещаний.

15 оригинальных заметок, ранее не отслеживавшихся Git, перенесены без изменения
содержимого в локальный `legacy-notes/` (исключён из Git). `manifest.json` внутри
него содержит исходные/новые пути и SHA-256. Оригиналы не публикуются вместе
с этой сводкой; их ссылки и код сохранены как исторический материал.

| Исходные заметки | Статус |
| --- | --- |
| Шаги 1–9: пакеты, UCI, init, библиотеки, кэш, демон, сборка, demo, хуки | Базовые этапы реализованы; текущие схемы и код отличаются от ранних примеров |
| Шаг 10: валидация | `make all` и локальные тесты реализованы; пробелы покрытия перечислены в ТЗ |
| Шаг 11: CI/CD | CI и артефакты реализованы; публикация релизов остаётся в TODO |
| Шаг 12: feed | Генератор индекса существует; проверка feed, публикация и доверие остаются в TODO |
| Архитектура «Ядро + Модули», проектная спецификация | Заменены актуальным ТЗ; расширения триггеров, модулей и опроса перенесены в TODO как предложения |
| Пошаговая организация окружения | Заменена DEVELOPMENT; дополнительная Ansible/IDE-интеграция остаётся предложением |

Ранние FIFO-примеры, reload без прерывания, оценки ресурсов и безусловная
сохранность UCI не являются текущими гарантиями. Актуальная доставка — JSONL;
границы восстановления описаны в ТЗ и VALIDATION. Команды из архива не запускать
как установочную инструкцию; публикацию feed и релизов этот этап не выполняет.
