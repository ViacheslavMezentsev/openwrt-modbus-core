## Документы пакетов

- [Ядро](core/README.md): ТЗ 1.7 и собственная история.
- [Demo](packages/demo/README.md): ТЗ 1.0, требования и проверки потребителя.
- [Schoolbell](packages/schoolbell/README.md): ТЗ 1.2, границы будущего пакета.

Каждый компонент ведёт свои README RU/EN, CHANGELOG RU/EN и русское ТЗ.
Старый TECHNICAL_SPECIFICATION.md оставлен как указатель. Новые ссылки на
требования/TC включают компонент. При выделении репозитория переносится вся
папка документации; ссылки на ядро заменяются ссылкой на фиксированную версию
контракта. Общая история и аппаратные результаты не переписываются.
