# Макет интерфейса schoolbell

[English](README.en.md) · [Пакет](../../../docs/packages/schoolbell/README.md)

Принятый визуальный эскиз на тестовых данных. Откройте [index.html](index.html)
в браузере непосредственно из файловой системы. Сборка, сервер, Интернет
и внешние библиотеки не нужны. При необходимости HTTP-просмотра на хосте:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory packages/schoolbell/ui-mockup
# Откройте http://127.0.0.1:8765; завершите сервер Ctrl+C.
```

## Что можно посмотреть

- Календарь из 12 месяцев: выбор даты, назначение обычного/сокращённого/
  экзаменационного расписания или тихого дня. 2027 год изначально пустой.
- Три тестовых расписания: изменение времени и выбор мелодии, сохранение
  только в памяти вкладки. Проверяется возрастающий порядок времени.
- Медиатека: демонстрационные карточки без загрузки файлов и прослушивания.
- Проигрыватель: ручное переключение пяти состояний, включая неопределённое
  завершение с удержанием ресурса.
- Одна кнопка темы в шапке: системная → тёмная → светлая. Выбор сохраняется
  в localStorage, если браузер разрешает; при запрете хранилища кнопка работает
  до закрытия страницы. Системный режим следует настройке ОС.

## Ограничения

Данные вымышленные; сводка следующего звонка, часы, журнал и прогресс —
фиксированные примеры, а не измерения. Изменения плана/расписаний сбрасываются
при перезагрузке; несохранённые изменения формы теряются при выборе другого
шаблона. Выбор темы хранится отдельно от этих временных данных.

Нет API, ядра, процессов, аудио, сети роутера, upload, импорта/экспорта,
публикации плана, операций со строками или управления оборудованием.
Макет не включён в IPK. Его упрощённый расчёт предзвонка не заменяет Lua-календарь:
нет полноценной обработки часовых поясов, переходов времени и полуночи.
Имена test.mp3 и тестовых мелодий не открывают реальные файлы.

Это эскиз для P07, не реализация и не приёмка требований TC-19–21/25–29
[ТЗ пакета](../../../docs/packages/schoolbell/TECHNICAL_SPECIFICATION.md).
Функциональный интерфейс, права доступа, общий вычислитель предпросмотра,
конфликты редактирования и постоянное хранение остаются в TODO.
Адаптивная разметка предусмотрена; аппаратная проверка планшета не выполнена.

## Ручная проверка

Открыть пять разделов; выбрать 2027 год и убедиться, что план пустой.
Назначить дате расписание, затем тихий день: список событий исчезает.
Изменить время, сохранить в макете и посмотреть события даты этого шаблона.
Переключить состояние проигрывателя и все три режима темы; обновить страницу:
план сбрасывается, тема сохраняется при доступном localStorage.
Эти проверки не подтверждают работу реального проигрывателя или пакета.

Исходники: index.html, style.css, app.js, theme.css, theme.js. Скриншоты,
логи просмотра и дублированный HTML с встроенными ресурсами не хранятся здесь.

Раздел «Настройки» показывает два маршрута: звук на устройстве пользователя через браузер и звук на колонках USB-аудиокарты роутера. Отдельные кнопки меняют только текст результата; аудио и сетевых запросов нет.
